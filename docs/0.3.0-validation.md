# MistyBanqi 0.3.0 validation

No trained net ships with the engine. `EvalFile` is empty by default, and failed
loads clear any previous net and report an `info string` error before returning
to classical evaluation. Evaluation files must remain outside the repository.

## Fixed-node fixtures

Both fixtures are retained unchanged from the original NNUE implementation.
Each uses 5,000 nodes per position and compares the entire `bestmove` line over
78 positions: 24 covered-tile openings, 24 midgames, 24 endgames, two clock-limit
cases, three root-filter cases and one quiet repetition window. Snapshots use
pieces from the initial multiset; the public bag contains exactly the identities
still covered. Move notation remains zero-based (`a0`–`h3`).

| Fixture | Reference | Positions |
| --- | --- | ---: |
| `banqi-engine/tests/fixtures/uci-v027.tsv` | Unmodified 0.2.7 binary | 78 |
| `banqi-engine/tests/fixtures/uci-net.tsv` | Independent BQNN reference UCI engine | 78 |

Expected moves came from the reference binaries, independently of this
implementation. The tests explicitly set `NoProgressLimit`, including 40 and 60,
and use `movetime 0` so wall time cannot bind. Neither fixture was regenerated
for this release. The NNUE fixture requires the same net as its reference run.
Fixtures establish equality for their recorded cases and budgets.

The retained generator accepts independently supplied binaries and an external
net path. It uses a 600,000 ms ceiling and asserts that the ceiling never binds.

## Net-mode settings

Only a successfully loaded net installs the evaluator and history-dependent rules.
The table describes normal search with `Noise=0`.

| Setting or behavior | Classical | Net loaded |
| --- | --- | --- |
| Leaf evaluation | Handcrafted | BQNN v2 quantized inference |
| Contempt | 0.1 | 0 |
| Capture-quiescence depth | 8 | 4 |
| Iterative-deepening ceiling | 24 | 64 |
| Position-only transposition table | Enabled, 2^18 entries | Disabled: history affects legality and draws |
| Repetition | Ancestor-match draw approximation | Exact third occurrence, with chase/flee exceptions |
| Chase move legality | Host root filter only | History-dependent restriction throughout the tree and quiescence, plus host root filter; forced-move exception retained |
| Effective feature mask | 1018 | 1008 (TT bit 2 and approximate-repetition bit 8 cleared) |
| Terminal root | Existing legal-move fallback behavior | Adjudicated before search; returns `bestmove (none)` |
| Score when no depth completes | Existing zero fallback | Net heuristic; move still uses the ordinary legal fallback |

Node accounting is unchanged: every visited search/quiescence node counts,
including the node that exceeds the budget. Clock checks remain every 1,024 nodes;
`movetime 0` means no wall-clock cap in both modes. The default no-progress limit
remains 40 and the UCI option controls both modes. Material values, mobility/general
weights, capture ordering, Star1 chance enumeration, root anti-draw-sac guard, move
notation and FEN parsing are unchanged. Move ordering and LMR feature bits remain off.

`Noise`, `NoiseDepth` and `Seed` work with both evaluators. With `Noise=0`, the
classical path delegates to the same search configuration as 0.2.8 before any
weak-play guards or random-number work. With noise enabled, the shared root
selection policy uses the active evaluator and rules, including exact chase
restrictions in net mode. A depth-one pass always completes; later passes share
the node/time limits, as in 0.2.8.

## Reproducing the checks

```sh
env -u MISTY_BANQI_EVALFILE cargo test --workspace
MISTY_BANQI_EVALFILE=/path/to/evaluation.bqnn cargo test --workspace
```

Without the variable, two trained-net checks print
`SKIP trained-net check: MISTY_BANQI_EVALFILE is unset` and return early. Cargo
counts these early returns as passed tests; they are reported separately below.
An explicitly set invalid path fails the checks.

All other tests run without a trained net. They cover public-state feature
encoding, synthetic BQNN v2 loading and inference, malformed files, integer
accumulator bounds, incremental updates, exact chase/repetition rules and a
search oracle, UCI option parsing and persistence, fallback after a failed load,
root filters, node/time limits, and classical/NNUE weak play. The 0.2.8 weak-play
tests retain their recorded moves, scores, depths and visited-node counts.

The repository scan walks files recursively, excluding `target/`, and rejects
both `.bqnn` filenames and files starting with `BQNN`. Its self-test plants a fake
`.bqnn` and a disguised magic-header file in a temporary directory outside the
repository, verifies that each is caught, and checks the `target/` exclusion.

Workspace tests also retain the macOS PyO3 test-export gate and extension linker
helper. The package-specific release stripping override preserves the Python
extension's LINKEDIT alignment; the UCI binary's release profile is unchanged.

## Release checks

| Workspace run | Cargo passes | Trained-net checks skipped | Failures |
| --- | ---: | ---: | ---: |
| `MISTY_BANQI_EVALFILE` unset | 113 | 2 (111 checks executed) | 0 |
| `MISTY_BANQI_EVALFILE` set to the reference net | 113 | 0 | 0 |

The totals comprise 63 engine tests, 25 browser-core tests and 25 Python-core
tests, plus zero doctests. Both fixed-node fixtures match all 78 expected moves.

A separate run compared an unmodified 0.2.8 binary from `a33cf01` with this
release on all 78 classical fixture positions. Bestmoves, centipawn scores,
completed depths and visited-node counts match exactly. The fixture files and
reference generator are byte-for-byte unchanged.

The source patch excluded the trained net before application. This release adds
one commit above `a33cf01`, with no `nets/` or `.bqnn` file and no blob beginning
with `BQNN` in its tree. The bundled-file usage, checksum and previous validation
counts were removed from the original release notes.
